# Система покадрового розфарбовування на основі лінійного перетворення сегментів

Програмна реалізація до магістерської курсової роботи зі спеціальності F3 «Комп’ютерні науки» (ОНП «Технології штучного інтелекту», факультет інформаційних технологій КНУ імені Тараса Шевченка).

## ⚠️ ВАЖЛИВО ПЕРЕД ЗАПУСКОМ (Вимога до шляху без кирилиці)

**Повний шлях до папки репозиторію та папки збереження результатів НЕ ПОВИНЕН містити кириличних (українських) символів!**

* ❌ **Неправильно:** `C:\Users\Віталій\Desktop\Репозиторій курсова\`
* ✅ **Правильно:** `C:\Projects\frame-colorization\`

**Причина:** модулі збереження зображень і відео (`cv2.imwrite` та `cv2.VideoWriter` з бібліотеки OpenCV у Windows) не підтримують кириличні символи у шляхах до файлів. За наявності кирилиці кадри не записуються на диск, і генерація відео завершується помилкою `Video file was not created`. Перед роботою перемістіть або склонуйте репозиторій у директорію, шлях до якої містить лише латинські літери, цифри та стандартні розділові знаки.

## Структура репозиторію та призначення файлів

### 1. Директорія з готовими даними для анімації (`procesed dataset/`)

Усі повністю підготовлені та оброблені набори даних персонажів, які можна одразу використовувати для розфарбовування та створення анімації, розташовані у папці **`procesed dataset/`**.

Для кожного персонажа у відповідній підпапці директорії `procesed dataset/` міститься повний комплект із чотирьох файлів:

* **`<id>.main.png`** (наприклад, `0101.main.png`, `0201.main.png`) — базовий контурний шаблон нульового кадру персонажа з прозорим фоном. Саме цей файл завантажується у графічний редактор для розфарбовування.
* **`<id>.meta.json`** (наприклад, `0101.meta.json`, `0201.meta.json`) — файл геометричних метаданих персонажа: містить глобальні габарити (`global_bbox`), карту UV-координат усіх масок (`uv_map`), ієрархію перекриття шарів (`layers`) та список сегментів для кожного кадру.
* **`<id>.atlas.png`** (наприклад, `0101.atlas.png`, `0201.atlas.png`) — одноканальний текстурний атлас усіх унікальних бінарних масок сегментів та контурів персонажа. Завантажується автоматично з тієї самої папки, де лежить `<id>.meta.json` (вручну обирати його не потрібно, але він обов'язково має знаходитися поруч із `.meta.json`).
* **`transform.json`** — файл попередньо обчислених матриць афінних деформацій ($2 \times 3$) для перенесення кожного сегмента з нульового кадру на всі наступні кадри послідовності.

### 2. Виконувані модулі (у корені репозиторію)

* **`painter_app.py`** — головний користувацький додаток із графічним інтерфейсом (PyQt5) для розфарбовування першого (нульового) кадру та запуску синтезу анімації.
* **`animation_system.py`** — діалогове вікно налаштування параметрів рендерингу та вибору вхідних і вихідних файлів.
* **`texture_animator.py`** — рушій покадрового перенесення текстур на основі матриць афінних перетворень та пакування кадрів у відеофайл `.mp4`.
* **`AtlasManager.py`** — допоміжний модуль вибірки бінарних масок сегментів із текстурного атласу за їхніми UV-координатами.
* **`calculate_transform_matrices.py`** — модуль офлайн-оптимізації матриць афінних деформацій ($2 \times 3$) на базі PyTorch (STN + OneSidedLoss).

### 3. Інші директорії репозиторію

* **`procesed dataset/`** — **основна папка з повністю обробленими даними персонажів** (`*.main.png`, `*.meta.json`, `*.atlas.png`, `transform.json`), готовими для запуску анімації.
* **`original dataset/`** — вихідні контурні послідовності кадрів персонажів до обробки.
* **`annotation/`** — скрипти первинної сегментації та міжфреймового трекінгу (`prepare_annotations.py`).
* **`Tools/`** — інструменти візуальної верифікації трекінгу, розмітки шарів перекриття (`layers_tool.py`) та пакування атласів (`prepare_data.py`).
* **`Output/`** — директорія за замовчуванням для збереження згенерованих кадрів та фінального відео.

## Покрокова інструкція: малювання та генерація анімації

### Крок 1. Запуск графічного редактора

Перейдіть у кореневу папку репозиторію (шлях без кирилиці!) та запустіть головний додаток:

```bash
python painter_app.py
```

### Крок 2. Завантаження контурного шаблону для малювання

1. На правій панелі керування у блоці **File** натисніть кнопку **`Load Image`**.
2. У провіднику відкрийте папку **`procesed dataset/`**, зайдіть у директорію потрібного персонажа та виберіть контурний файл **`<id>.main.png`** (наприклад, `0101.main.png`).
3. На полотні з’явиться контурне зображення персонажа (нульовий кадр).

### Крок 3. Розфарбовування персонажа

Розфарбуйте персонажа за допомогою інструментів на правій панелі:

* **Brush** — звичайний пензель;
* **Fill Bucket** — суцільна заливка замкнутих сегментів одним кліком;
* **Glitter Brush** — текстурний пензель з ефектом блискіток;
* **Eraser** — гумка;
* **Protect Contours** *(увімкнено за замовчуванням)* — захист чорних контурних ліній від випадкового зафарбовування;
* **Color / Quick Palette / Brush Size** — вибір кольору та розміру пензля.

### Крок 4. Вибір файлів для обробки та запуск синтезу відео

1. Після завершення розфарбовування натисніть кнопку **`Create Animation`** у правому нижньому куті головного вікна (блок **Animation**).
2. Відкриється вікно **`Animation Creator`**. У блоці **Required Files** вкажіть файли з тієї самої папки персонажа всередині **`procesed dataset/`**:
   * **`meta.json`** $\rightarrow$ натисніть **`Browse...`**, перейдіть у **`procesed dataset/`** (папка обраного персонажа) та виберіть **`<id>.meta.json`** *(переконайтеся, що поруч із ним у тій самій папці лежить `<id>.atlas.png`)*.
   * **`transform.json`** $\rightarrow$ натисніть **`Browse...`** та виберіть файл **`transform.json`** з папки цього ж персонажа у **`procesed dataset/`**.
   * **`Painted Frame 0`** $\rightarrow$ підставляється автоматично з вашого поточного малюнка на полотні.
   * **`Output Folder`** $\rightarrow$ натисніть **`Change...`** та виберіть папку, куди збережеться готове відео (наприклад, папку `Output` у корені репозиторію; **шлях до папки не повинен містити кирилиці!**).
3. Натисніть кнопку **`Create Animation`** у нижній частині діалогового вікна.

### Крок 5. Де знайти та переглянути готове відео

* Дочекайтеся завершення обробки в полі **Progress** (з’явиться повідомлення `Animation complete!` та шлях до збереженого відео).
* **Зверніть увагу:** у самому вікні додатка готове відео **не відтворюється** (інтерфейс призначений виключно для малювання та запуску генерації).
* Щоб переглянути результат, відкрийте в провіднику папку, яку ви вказали в полі **`Output Folder`** (за замовчуванням — папка **`Output/`** у корені репозиторію):
  * **`animation.mp4`** — готовий відеофайл анімації вашого розфарбованого малюнка (30 FPS);
  * **`frame_0000.png` ... `frame_XXXX.png`** — окремі синтезовані кадри послідовності.
